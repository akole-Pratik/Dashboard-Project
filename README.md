# 🎯 Customer Purchase Behaviour Analysis

## Problem Statement 
Develop an interactive dashboard that analyses customer purchasing patterns, preferences, and trends.

## Overview
The primary objective of this project is to develop an interactive dashboard for analysing customer purchasing behaviour. The dashboard will help businesses identify trends, preferences, and patterns, enabling them to make data-driven decisions. Specifically, the dashboard aims to answer the following:
1.	What is the frequency of purchases by Gender??
2.	What are the most purchased items category?
3.	Which item categories are the most popular in different locations?
4.	What items are most commonly purchased during each season?

## 🚀 Features
- 📊 **Dynamic KPI Indicators** 
- 🔍 **Interactive Filtering**
- 📈 **Data Visualization & Charts**
- ⚡ **Fast & Responsive UI**
